# Frontend (React + Vite)

## Environment configuration

Create a `.env` file in this folder when running against the Laravel API.

```env
VITE_API_BASE_URL=http://localhost:8000/api
VITE_BACKEND_BASE_URL=http://localhost:8000
```

- `VITE_API_BASE_URL` is used for API requests.
- `VITE_BACKEND_BASE_URL` is used to open uploaded slip files from the admin dashboard.

## Run

```bash
npm install
npm run dev
```
